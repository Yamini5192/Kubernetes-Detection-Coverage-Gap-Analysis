# Assessment Reports

This directory contains the leadership summary, technical analysis, and sanitized evidence index for the Falco Kubernetes detection assessment.

## Deliverables

- [Executive summary](executive-summary.md) — findings, measured baseline, and prioritized actions.
- [Technical report](coverage-gap-analysis.md) — methodology, scenario results, limitations, and detailed recommendations.
- [Sanitized evidence register](evidence-register.md) — reviewed summaries of local raw artifacts.

The raw `evidence/` directory is excluded from Git. The reports distinguish tested outcomes from limitations and unmeasured behavior; the evidence register is not a substitute for access to raw captures.
